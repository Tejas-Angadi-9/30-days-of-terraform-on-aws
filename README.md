# Terraform 30-Day Challenge

This repository documents my learning journey through a 30-day Terraform challenge focused on using Terraform with AWS. I am following the [AWS Terraform Full Course for Beginners (with Real-Time Projects)](https://www.youtube.com/playlist?list=PLl4APkPHzsUWr5H7mprC8O21Crq_NnbYx).

**Started:** 20 November 2026

**Target completion:** 20 December 2026. I'm aiming to finish the challenge by learning Terraform consistently every day.

## What I'm learning

I learn by following the instructor's lessons and working through the examples. I take time to understand the concepts, check behavior in the browser and consult the documentation, then implement the examples and experiment through trial and error. I also ask AI for help when I need a clearer explanation or a better understanding.

## Repository structure

Exercises are organized into day-specific directories. For example, `day02/` contains the Terraform configuration and provider lock file for that day's work. I plan to add more directories as I continue the challenge.
